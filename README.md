## 🔒 Privacy & Data Storage (Zero Backend)

TypeForge is completely **serverless** and respects your privacy. 

- **Local First:** All your progress, XP, streaks, and settings are saved locally in your browser using `localStorage`.
- **No Accounts Required:** Jump straight in without signing up.
- **Data Portability:** Easily export your data to a `.json` file and import it on another browser or device.
- **Danger Zone:** 1-click option to permanently delete all your data and start fresh.

## ⚙️ How to Run Locally

Because TypeForge uses no server-side code, running it locally is incredibly simple:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/TypeForge.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd TypeForge
   ```
3. **Open the file:**
   Simply double-click `index.html` to open it in your default web browser.
   *Alternatively, use an extension like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code for hot-reloading.*

## 🌍 How to Deploy to GitHub Pages

Deploying TypeForge takes less than 2 minutes:

1. Create a new public repository on GitHub.
2. Upload the `index.html` file to the root of the repository.
3. Go to your repository **Settings**.
4. On the left sidebar, click on **Pages**.
5. Under **Build and deployment**, set the Source to **Deploy from a branch**.
6. Select the `main` (or `master`) branch and the `/ (root)` folder, then click **Save**.
7. Wait a minute or two, and your live URL will appear at the top of the Pages settings!
